# Табата таймер

Интервальный таймер: https://tabata-5c275.web.app/ (старый адрес https://miketoreno88.github.io/tabata/ перенаправляет туда)

- Круги списком: у каждого своё время работы и отдыха, "+ Добавить круг" копирует последний. По умолчанию 8 кругов по 1:00 работы и 1:00 отдыха.
- Порядок кругов меняется перетаскиванием за номер (мышь, палец, стрелки с клавиатуры).
- Подготовка и заминка, готовые наборы (1:00 / 1:00, Табата, Табата × 3, 40/20, 30/30).
- Звуковые сигналы смены фазы и отсчёт 3-2-1, экран не гаснет во время тренировки.
- 10 языков: русский, английский, испанский, немецкий, французский, португальский, итальянский, турецкий, китайский, японский. Язык берётся из настроек браузера, переключатель в шапке.
- Настройки и выбранный язык хранятся в браузере (localStorage).

## На экран Домой

- iPhone: открыть сайт в Safari, "Поделиться", затем "На экран Домой".
- Android: в Chrome кнопка "Установить" на табло или меню браузера, "Добавить на главный экран".

После первого открытия таймер работает и без интернета (`sw.js`).

## Файлы

- `index.html`: весь таймер (разметка, стили, скрипт).
- `manifest.webmanifest`, `icons/`: название и иконки приложения.
- `sw.js`: кеш для работы без сети.
- `cloud.js`, `firebase-config.js`: вход (Google, почта и пароль) и тренировки в Firestore.
- `firestore.rules`: каждый видит и меняет только свои тренировки (`users/{uid}/workouts/{id}`).
- `firebase.json`, `.firebaserc`: хостинг и правила, проект `tabata-5c275`.

## Выкладка

```
npx firebase-tools deploy --only hosting,firestore:rules
```

GitHub Pages остаётся только ради перенаправления со старого адреса.
