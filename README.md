# Табата таймер

Интервальный таймер в одном файле `index.html`: открыть в браузере, ничего ставить не нужно.

- Круги списком: у каждого своё время работы и отдыха, "+ Добавить круг" копирует последний.
- Порядок кругов меняется перетаскиванием за номер (мышь, палец, стрелки с клавиатуры).
- Подготовка и заминка, готовые наборы (Табата, Табата × 3, 40/20, 30/30).
- Звуковые сигналы смены фазы и отсчёт 3-2-1, экран не гаснет во время тренировки.
- Настройки хранятся в браузере (localStorage).
